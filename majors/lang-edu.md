# 외국어·어학교육 전공 도메인 제약 및 기술 지침 (`lang-edu.md`)

외국어 원서 강독, 발음·성조·뜻 병기, 문맥 기반 단어 학습 웹앱을 구현할 때 준수해야 하는 도메인 지침입니다.

---

## 1. 인라인 루비 태그(`<ruby>`) 모델링 및 검색 무결성

1. **원자적 인라인 노드 (`atom: true`)**:
   - TipTap/ProseMirror에서 `<ruby>원문<rt>발음·번역</rt></ruby>`은 `atom: true` 인라인 노드로 정의해, 백스페이스 1회로 주석과 함께 깔끔히 삭제되며 내부 커서 쪼개짐을 방지한다.
   - 마크다운 왕복 직렬화(`<ruby>base<rt>annotation</rt></ruby>`)를 지원한다.
2. **검색 및 토크나이징 무결성 (`plainTextOf`)**:
   - 노트의 평문 추출(`plainTextOf`) 및 오프라인 검색 인덱싱 시 `<ruby>` 노드에서 `<rt>` 주석만 분리하거나 원문(`base`) 텍스트를 온전하게 유지해, 루비 주석을 달아도 원문 어휘 검색이 깨지지 않도록 보장한다.

---

## 2. 3가지 번역 결과 삽입 모드 및 공백 보존

학습자의 선호와 읽기 목적(원서 직독직해 vs 문장 번역본 정리)에 따라 번역 삽입 방식을 설정 가능하게 제공한다.

| 모드 ID | 동작 방식 | 예시 (`ring` 선택 시) |
| :--- | :--- | :--- |
| **`parentheses`** (기본) | 원문 바로 뒤에 괄호로 번역 삽입 (후속 문장 보존) | `ring (고리, 반지)` |
| **`ruby`** | 원문 위에 작은 루비 주석(`<ruby><rt>`) 표시 | `<ruby>ring<rt>고리, 반지</rt></ruby>` |
| **`replace`** | 원문을 번역 문장으로 대체·덮어쓰기 | `고리, 반지` |

- **공백 보존 규칙**: ProseMirror 범위 `{ from, to }` 치환 시 선택 영역 앞뒤의 공백(`leading`, `trailing`)을 정규식으로 분리해 보존함으로써, 단어 간 띄어쓰기가 붙거나 중복 공백이 생기는 현상을 방지한다.

---

## 3. 점진적 적응형 문맥 번역 사전 (Adaptive Glossary)

동일한 영단어라도 문맥과 전공에 따라 의미가 달라지는 다의어(`ring`: 고리/반지 vs 환(環), `field`: 분야/들판 vs 체(體)/장(場))를 로컬에서 1ms 미만으로 정확히 분기하고 학습한다.

1. **문맥 공기어(Co-occurrence) 스코어링**:
   - 선택 단어 단독이 아니라 주변 문장과 문서 `#태그`·제목 내 공기어를 함께 분석해 최적 의미를 선택한다.
2. **굴절어·복수형 정규화 (Stem Matching)**:
   - 원서 읽기 중 복수형(`rings`, `fields`, `ideals`)을 드래그하더라도 양 끝 구두점 제거 및 `-s`/`-es` 어미 정규화를 거쳐 단수형 시드 사전과 매칭한다.
3. **도메인 가중치 편향 중립화 (`baseWeight`)**:
   - 특정 전공 뜻의 `baseWeight`를 타 분야보다 과도하게 높게 설정하면 문맥 트리거가 없는 일반 문장에서도 전문 용어로 오역된다.
   - 각 전문 분야 `baseWeight`는 동등하게 유지해, 문맥 트리거 부재 시 일반 기본값(`defaultMeaning`)과 사용자의 로컬 학습 빈도를 우선한다.
4. **자가 학습 피드백 루프 (IndexedDB 영속화)**:
   - 사용자가 대안 번역을 선택하거나 직접 수정 입력 시 문장 내 핵심 명사 키워드(최대 6개)와 함께 `IndexedDB`에 저장해, 이후 유사 문맥에서 Tier 1 로컬 추천(신뢰도 `>= 70%`)으로 최우선 승격한다.
   - Tier 1 미매칭 단어·구문·통문장만 Tier 2(BYOK 무료 AI) → Tier 3(공개 무키 번역)으로 위임해 API 비용을 절감한다.
