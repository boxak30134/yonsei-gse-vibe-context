# 브라우저 내 PDF·문서 페이지 규격 관리 및 내보내기 패턴 (`pptx-client-export.md`)

브라우저 및 태블릿 웹뷰 환경에서 PDF·슬라이드 문서를 가져와(Import) 고해상도로 렌더링하고, 표준 용지 규격 메타데이터를 유지하며, 클라이언트 측에서 PDF/PPTX로 내보내거나 썸네일을 생성할 때 준수해야 하는 기술 패턴입니다.

---

## 1. 표준 용지 규격 및 4px/mm 좌표 스케일 매핑

필기 스트로크·주석·텍스트 객체 좌표계와 실제 인쇄/내보내기 용지 비율을 일치시키기 위해 표준 용지 규격을 `4px/mm` 비율로 정의한다.

| 규격 | 물리 크기 (mm) | 픽셀 치수 (Portrait, 4px/mm) | 비고 |
| :--- | :--- | :--- | :--- |
| **A4** (기본) | `210 × 297 mm` | `840 × 1188 px` | 기본 노트·PDF 기준 폭과 비율 일치 |
| **A3** | `297 × 420 mm` | `1188 × 1680 px` | 대형 도표·마인드맵 |
| **A5** | `148 × 210 mm` | `592 × 840 px` | 소형 메모 |
| **B5** | `176 × 250 mm` | `704 × 1000 px` | 한국/일본 표준 노트 |
| **Letter** | `216 × 279 mm` | `864 × 1116 px` | 북미 문서 호환 |

- **방향(`orientation`) 및 스타일(`style`) 메타데이터 보존**:
  - 각 페이지는 `size`, `orientation` (`'portrait' | 'landscape'`), `style` (`'plain' | 'lined' | 'grid' | 'dotted'`) 속성을 개별 보유한다.
  - PDF/PPTX 내보내기 시 각 페이지의 개별 규격(`A4`, `A3` 등), 방향(가로/세로 혼합 문서 지원), 배경 줄/모눈 스타일을 그대로 출력 페이지 크기에 매핑한다.
- **문서 포맷 실시간 전환**:
  - `paginated`(페이지 분리형)와 `continuous`(연속 단일 페이지) 모드를 지원하되, PDF 임포트 문서는 페이지 경계가 명확한 분리형 레이아웃을 유지한다.

## 2. PDF 가져오기(Import) 시 렌더링 누락·중복 방지 패턴

### 2.1 `operationsFilter` 사용 금지 (본문 상단 빈 공간 버그)
- `pdf.js` 페이지 렌더링 시 `TEXT_OPS`나 `IMAGE_OPS`를 제외하는 필터를 걸면 강의 슬라이드·교재 PDF의 인쇄 텍스트와 본문 이미지가 통째로 지워져 페이지 상단 80%가 흰 빈 공간으로 남는다.
- **규칙**: `page.render()`는 필터 없이 원본 PDF의 텍스트·수식·이미지·손글씨를 100% 렌더링한다.

### 2.2 XObject 중복 마운트 금지 & `plainText` 검색 분리
- 외부 필기 앱에서 내보낸 PDF는 손글씨 레이어가 내부 XObject 이미지로 포함될 수 있다. `page.render()`가 이미 페이지 전체를 단일 템플릿으로 그리므로, XObject 이미지를 별도 `{ type: 'image' }` 노드로 추가 추출·마운트하면 페이지 하단에 손글씨가 중복 출력된다.
- **규칙**: 페이지당 정확히 1개의 `inkTemplate` 노드만 마운트하고, 추출한 OCR/텍스트 레이어는 화면에 중복 렌더링하지 않고 검색용 `plainText` 필드에만 저장한다.

### 2.3 고해상도 썸네일 & 메모리/Blob URL 관리
- PDF 고해상도 벡터 렌더링 시 `scale = Math.min(2, 2400 / Math.max(w, h))` 상한을 적용해 대용량 PDF의 메모리 폭증을 막고, 페이지 이미지 바이너리는 OPFS(Origin Private File System)에 스트리밍 저장한다.
- 썸네일 리스트에서 `URL.createObjectURL()`로 생성한 객체 URL은 반드시 `useEffect` 클린업에서 `URL.revokeObjectURL()`로 해제해 100페이지 이상 문서에서 메모리 누수를 차단한다.

## 3. 사용자 생성 페이지 실시간 썸네일 합성 & 클라이언트 내보내기 가이드

- **일반 페이지 썸네일(`PagePreviewCanvas`)**: PDF 이미지가 없는 일반 페이지는 각 페이지 세로 오프셋($Y_i$) 구간에 속한 텍스트 단락(CSS 축소 프리뷰), 손글씨 스트로크(벡터 `drawStroke` 캔버스), 용지 스타일(`plain`/`lined`/`grid`/`dotted`)을 합성해 실시간 미리보기를 생성한다.
- **클라이언트 PPTX / PDF 내보내기 공통 수칙**:
  1. 대용량 이미지/폰트 처리 시 메인 스레드 UI 프리징 방지를 위해 청크 단위 비동기 처리 및 진행률 표시를 제공한다.
  2. 내보내기 시 용지 여백 오차(`0px`)를 위해 PDF 페이지 간 화면용 gap(`PDF_PAGE_GAP_PX = 24px`)은 출력 좌표에서 제외하고 각 페이지의 로컬 좌표(`0 ~ pageHeight`) 기준으로 스트로크·텍스트 객체를 변환한다.
  3. 폰트 임베딩 시 사용자가 등록한 커스텀 한글 폰트(`.ttf`/`.otf`, 최대 30MB) 또는 기본 한글 폰트가 누락되어 글자가 깨지지 않도록 폴백을 명시한다.
